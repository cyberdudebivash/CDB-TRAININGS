# Licence Status

**There is no `LICENSE` file in this repository on purpose.** Choosing a licence is a decision for the copyright holder, and the audit found the holder is not stated in most source documents (`docs/audits/IP_AND_LICENSE_REVIEW.md`, risk table and actions A2-A6). Until the owner decides, **all rights are reserved**; being publicly visible on GitHub does not grant reuse rights.

This file is an engineering summary, **not legal advice**.

## What exists, and what rights position each part is in

| Content | Origin | Position |
|---|---|---|
| Ten source PDFs (repository root) | Supplied by the owner | Rights-holder not confirmed for 8 of 10; unchanged and preserved; not to be redistributed or sold until A2-A5 are resolved |
| Audit documents, catalog, pathways, standards, release/QA reports | Written for this repository | Owner decides licence and copyright holder |
| SOC-M04 lesson, labs, assessments, scripts, tests, design system | Original work written for this repository | Owner decides; recommended split below |
| Third-party material quoted | MITRE ATT&CK, NIST, Microsoft Learn, Sigma specification | Cited minimally with attribution; see `shared/templates/attribution-notices.md` |
| Python dependencies (PyYAML, jsonschema, pytest, pypdf, javalang, pySigma) | Upstream open-source packages | Installed from PyPI, not redistributed in this repository; check each licence before bundling any of them |

## Recommendation for the owner (decision D4)

| Part | Suggested model | Reason |
|---|---|---|
| Course text (lessons, student editions) | All rights reserved, or a source-available licence | Commercial product |
| Code (lab harnesses, evaluators, generators, build scripts, tests) | Apache-2.0 or MIT | Lets learners reuse and extend labs |
| Datasets generated by the lab generator | Same as code | Reproducible by seed anyway |
| Instructor pack | Private, not distributed with the public repository | Contains answer keys |

## Third-party notices that must travel with distributed material

- MITRE ATT&CK®: "© 2026 The MITRE Corporation. This work is reproduced and distributed with the permission of The MITRE Corporation." (terms page verified 2026-10-14; the page does not address derivative works, so counsel should confirm for modified content).
- NIST publications are cited by number and date; no endorsement is implied.
- SigmaHQ rules are under the Detection Rule License 1.1; the pilot's rules are original and none were copied.
- OSINT tools (theHarvester GPL-2.0-only, recon-ng GPL-3.0, Sherlock MIT) must **not** be re-licensed or bundled as proprietary (finding F-OSINT-002).
