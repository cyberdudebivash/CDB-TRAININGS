> publication (`ACADEMY_LIVE_GO`) are separate gates that are not part of this phase and are not assessed here.

A *course edition* is the PDF built from the whole approved curriculum of a course. A module preview is not a course edition and cannot satisfy criterion A14, and neither can a complete-course *preview* (every module in one PDF, built from content that nobody has reviewed or approved). A PDF built while any required module is missing fails the build gate.

## 3. Gates every edition must pass

- Built only from tracked source files whose sha256 values are recorded; a stale manifest (sources changed after the build) is not evidence.
- Student edition contains no instructor key, answer or hidden-test content; the refusal list and forbidden markers are enforced by `scripts/build/build_student_edition.py`.
- Text of the built edition is scanned by the personal-data guard (`scripts/validation/check_privacy.py`).
- Tagged PDF, bookmark outline, 360 px layout without horizontal overflow, contrast pairs meet WCAG.
