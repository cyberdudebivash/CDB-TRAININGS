Role-oriented learning pathways assembled from the module catalog. Levels describe **learning evidence inside this academy** (what a learner can demonstrate), not job titles, salary bands or equivalence to any external certification. Hours are planning estimates (authoring budgets), not measured learner times. No module except the SOC-M04 pilot is built yet, so every other module below is `PLANNED`.

## Competency levels

| Level | Name | Descriptor | Evidence of attainment | Supervision |
|---|---|---|---|---|
| 0 | Foundations | Completes guided tasks in a safe, prepared environment by following written steps. | Automated checks pass on small guided exercises; learner can restate what each step did. | Every task is scaffolded; learner is expected to ask for help. |
| 1 | Guided practitioner | Performs routine tasks from a documented procedure and recognises when a result looks wrong. | Rubric-scored short artefacts (a parsed log, a unit-tested function, a defect report) built from provided starters. | Output is reviewed before it is relied on. |
| 2 | Independent practitioner | Completes standard tasks without a starter, justifies trade-offs, and validates their own work against data or tests. | Independent labs graded by automated checks plus a rubric; learner measures precision/recall, coverage or runtime rather than asserting them. | Self-checked; periodic review. |
| 3 | Advanced practitioner | Handles ambiguous, multi-step problems that cross domains; designs, evaluates and documents solutions for others to use. | Capstone with a reproducible repository or case file, a written decision record, and an evaluation against stated acceptance criteria. | Reviews others' work; owns outcomes. |
