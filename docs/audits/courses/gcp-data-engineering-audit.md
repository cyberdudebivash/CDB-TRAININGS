### F-GCP-001 (P1) CI examples authenticate with a long-lived service-account JSON key

- **p. 179:** `echo "${{ secrets.GCP_SA_KEY }}" | base64 -d > sa.json` then `gcloud auth activate-service-account --key-file=sa.json`.
- **p. 180:** Same pattern repeated; also p. 182.

Google recommends Workload Identity Federation over keys; for organisations created on/after 2024-05-03 key creation is blocked by default, so the example fails there.

*Reference R-014:* google-github-actions/auth README - authentication options - Google (open-source GitHub Action), README as of 2026-10-14 (verified 2026-10-14, method OFFICIAL_PAGE_SUMMARY).

*Reference R-015:* Google Cloud IAM - Best practices for managing service account keys - Google Cloud, as published 2026-10-14 (verified 2026-10-14, method OFFICIAL_PAGE_SUMMARY).

**Verification:** PRIMARY_SOURCE. **Recommendation:** Teach Workload Identity Federation (OIDC) for GitHub Actions with least-privilege roles.
**Remediation:** PLANNED_IN_TRACK - Track GCP-6.
