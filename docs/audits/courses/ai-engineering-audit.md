### F-AI-001 (P1) Flagship RAG lab does not run on the current LangChain stack

- **p. 400:** requirements list is unpinned (openai, langchain, faiss-cpu, tiktoken, python-dotenv).
- **p. 401:** Imports langchain.embeddings.OpenAIEmbeddings and langchain.vectorstores.FAISS (build_embeddings.py).
- **p. 403:** Imports langchain.llms.OpenAI and calls llm(prompt) with temperature=0.

On langchain 1.4.5 all three imports fail (ImportError / ModuleNotFoundError). A learner following the lab today hits errors before the first query.

*Reference R-004:* LangChain 1.x import-path removal (reproduced) - PyPI / LangChain, langchain 1.4.5, langchain-core 1.6.10, openai 3.31.0, faiss-cpu 1.15.1 (latest at test time) (verified 2026-10-14, method EXECUTED).

**Verification:** EXECUTED. **Recommendation:** Rebuild the lab with pinned versions, current provider packages and a local/offline model option so it is free to run.
**Remediation:** PLANNED_IN_TRACK - Track AI-3.

### F-AI-002 (P1) RAG lab safeguards are dead code: refusal path never fires and governance prompts are never loaded

- **p. 404:** `if not context: print('Insufficient information available.')` - similarity_search(k=3) returns documents whenever the index is non-empty.
- **p. 402:** system_prompt.txt, task_prompt.txt and validation_prompt.txt are defined; app.py builds its own prompt and never reads them.
- **p. 404:** Retrieved text and user query are concatenated into the prompt with no injection controls.

The lab claims 'enterprise-style, defensible' grounding while the stated refusal and validation behaviour cannot occur.

**Verification:** MANUAL_READ. **Recommendation:** Use a relevance-score threshold for refusal, load/version prompts, add an answer-grounding check and an injection test set.
**Remediation:** PLANNED_IN_TRACK - Track AI-3.

### F-AI-003 (P1) 'Agentic' safety lab implements none of the controls its README claims

- **p. 421:** README claims tool allowlists, kill switches and human-in-the-loop.
- **p. 424:** Intent classifier is a substring test for 'outage'; planner is a fixed list; no LLM is involved.
- **p. 425:** Validator is a substring denylist (execute/shutdown/delete).
- **p. 426:** is_tool_allowed() is defined but the controller never calls it.
- **p. 427:** Audit log uses datetime.utcnow() (deprecated; raises DeprecationWarning under -W error on Python 3.13).

No kill switch, timeout, tool-call enforcement or tamper-evident audit trail exists in code.

*Reference R-018:* datetime.datetime.utcnow() deprecation (reproduced) - Python Software Foundation, CPython 3.13.16 (verified 2026-10-14, method EXECUTED).

**Verification:** EXECUTED. **Recommendation:** Build an agent harness with enforced tool permissions, step/time budgets, approval gates and adversarial tests.
**Remediation:** PLANNED_IN_TRACK - Track AI-4.
