# IP and Licence Review

> This is an engineering risk review, **not legal advice**. Items marked LEGAL_REVIEW need a qualified lawyer before the
> content is distributed or sold. Unknowns are stated as unknowns.

## 1. Rights status of the repository

| Item | Status |
|---|---|
| LICENSE file | **None.** Without a licence, all rights are reserved by the copyright holder; the repository is nevertheless **public**, so anyone can read, and GitHub's terms allow viewing/forking but grant no further rights. |
| Copyright holder | Not stated in 8 of 10 PDFs. The Java PDF has one copyright / all-rights-reserved line; the SOC playbook has a (c) 2026 CyberDudeBivash Pvt. Ltd. footer. Whether the entity or individual authors own the text is **unconfirmed** (owner decision D4). |
| Contributor agreements | None known. |
| Trademarks | Third-party product, vendor and certification names appear (Fortinet/FortiSIEM, Splunk, CrowdStrike, GIAC, OffSec, CompTIA, Google Cloud, etc.). Nominative use is normal, but implied endorsement is not (see IP-6). |

Recommendation (owner to decide): add a LICENSE that matches the commercial model, for example *all rights reserved* for
paid course text and *Apache-2.0 or MIT* for code samples and lab harnesses so learners can reuse code. New code in this
repository is not yet licensed pending that decision.

## 3. Rules adopted for new content in this repository

1. New lessons, labs and tests are **original text and code**; nothing is copied from the source PDFs. Facts are cited to primary
   sources in `docs/research/research_register.yaml`.
2. Third-party standards are quoted minimally with attribution; MITRE ATT&CK pages carry the required notice
   (`shared/templates/attribution-notices.md`).
3. Labs use **synthetic data generated by code**; no leaked-credential corpora, no real personal data, no real victim or
   brand names (reserved/example domains only: `example.com`, `example.org`, RFC 5737 IP ranges).
4. No third-party tool is redistributed. Labs install from upstream package registries at pinned versions.
5. Instructor-only material is excluded from this public repository and from student artefacts.
6. Personal data found in a source is never copied; evidence files store masked forms only.
7. Pricing, endorsement and outcome claims follow `docs/commercial/COMMERCIAL_READINESS.md`: no guarantees, no percentile
   or "ahead of X%" claims, no salary promises.
