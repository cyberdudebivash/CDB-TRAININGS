- **Compatibility, Security, Migration, Test environment** are derived from the deprecation rules (`docs/research/deprecation_rules.yaml`) and the executed probes (`docs/research/data/api_probes_2026-10-14.json`) that concern the technology. A technology with no rule and no probe has none of these and is listed in the compact tables.
- **GitHub release data was not collected.** The session's GitHub scope is restricted to this repository, so 31 registry entries whose only version source is a GitHub repository are `SKIPPED_GITHUB_NOT_ENABLED`.
- Facts about standards, frameworks and vendor lifecycles (not package versions) are in section 7 with their register ids; the evidence method for each is in [RESEARCH_VERIFICATION_2026.md](RESEARCH_VERIFICATION_2026.md).
