## Current usable training artifact

Its synthetic customer scenario is: A customer-support AI proposes which tool to invoke; the execution service must not grant permissions simply because model output claims it is authorized.

**Outcomes from this starter:** Agent permission boundary, treating model output as data, explicit human gate. The lab establishes a concrete exercise with positive and negative cases and requires no paid cloud/API subscriptions.
