# FND-M02 knowledge check (8 questions)

Formative: it checks understanding of the lesson and is **not** evidence of competence on its own (the independent lab is). The answer key is held by instructors and is not published.
Questions are generated from `quiz.yaml`; each is tied to a learning outcome.

| # | Outcome | Question | Options |
|---|---|---|---|
| Q1 | LO1 | What determines the resolution of a relative input file path? | A) The process current working directory. B) The router gateway. C) The CPU model. D) The screen resolution. |
| Q2 | LO1 | What is the relevant PowerShell command to inspect the current location? | A) Get-Location. B) chmod 777. C) kill -9. D) format C:. |
| Q3 | LO2 | When the synthetic CLI deliberately returns 3 under --fail-on-error, what does it mean? | A) An expected alert policy matched. B) The kernel crashed. C) The network was breached. D) A real customer was attacked. |
| Q4 | LO2 | Which stream should normally carry parseable command results? | A) Standard output. B) Standard error. C) Shell history. D) Keyboard layout. |
| Q5 | LO3 | Why avoid interpolating raw user text into a shell command? | A) Shell syntax could interpret additional operations. B) It guarantees faster execution. C) It automatically anonymizes logs. D) It removes filesystem races. |
| Q6 | LO3 | What is achieved by passing an explicit argument array without a shell? | A) It avoids another shell parsing layer. B) It guarantees the called program is harmless. C) It grants business authorization. D) It disables operating-system permissions. |
| Q7 | LO4 | How should a fictional replay dataset be described in an operational report? | A) Synthetic or replay evidence, not verified live customer telemetry. B) Live customer detection accuracy. C) Proof of attacker attribution. D) A completed enterprise incident. |
| Q8 | LO4 | What is the appropriate response to a malformed CSV status 2? | A) Check and document the declared input contract. B) Suppress all diagnostics. C) Modify production permissions. D) Treat malformed data as a confirmed attack. |

**Scoring:** instructors apply the key; 6/8 is the formative checkpoint.
