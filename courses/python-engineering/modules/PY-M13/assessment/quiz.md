Formative: it checks understanding of the lesson and is **not** evidence of competence on its own (the independent lab is). The answer key is held by instructors and is not published.
Questions are generated from `quiz.yaml`; each is tied to a learning outcome.

| # | Outcome | Question | Options |
|---|---|---|---|
| Q1 | LO1 | `gen = (x for x in range(3))`, then `first = list(gen)` and `second = list(gen)`. What are `first` and `second`? | A) `[0, 1, 2]` and `[0, 1, 2]`: a generator expression restarts for each list(). B) `[0, 1, 2]` and `[0, 1, 2]` only if `gen` is converted to a list first. C) `[0, 1, 2]` and `[]`: a generator is an iterator, and an exhausted iterator stays exhausted. D) `[0, 1, 2]` and a `StopIteration` exception. |
| Q2 | LO1 | A function contains `print("start")` followed by `yield 1`. What does the statement `g = f()` print? | A) Nothing: calling a generator function only creates the generator; the body runs when the first item is requested. B) `start`, because the body runs up to the first `yield` at the call. C) `start`, and then the generator is exhausted. D) Nothing, and `g` is `None`. |
| Q3 | LO2 | `def chunks(items, size):` begins with `if size < 1: raise ValueError` and later contains `yield`. When is the ValueError raised for `chunks([1, 2], 0)`? | A) At the call `chunks([1, 2], 0)`. B) Never: generators do not raise exceptions. C) When the interpreter compiles the function. D) At the first `next()` (or the first loop iteration), not at the call. |
| Q4 | LO2 | A generator opens a file with `with open(path) as f:` and yields its lines. The consumer reads one line and calls `gen.close()`. What happens to the file? | A) It stays open until the program ends. B) It is closed: `close()` raises GeneratorExit at the `yield`, which leaves the `with` block. C) It is closed only if the consumer also calls `f.close()`. D) It is closed only when the generator is exhausted. |
| Q5 | LO3 | `fs = [lambda: i for i in range(3)]`. What is `[f() for f in fs]`? | A) `[2, 2, 2]`: each lambda reads the variable `i`, which holds 2 when they are called. B) `[0, 1, 2]`: each lambda remembers the value `i` had when it was created. C) `[0, 0, 0]`. D) A `NameError`, because `i` no longer exists after the comprehension. |
| Q6 | LO4 | A decorator's wrapper is `def wrapper(): return func()`. Which of these is NOT a consequence? | A) Decorated functions that take parameters cannot be called. B) The decorated function's name and docstring become those of `wrapper`. C) The decorator is applied from the bottom up when stacked. D) It works for no-argument functions only, and the arguments of the original call are lost. |
| Q7 | LO4 | `@functools.lru_cache(maxsize=None)` decorates `def total(items): return sum(items)`. What happens for `total([1, 2, 3])`? | A) It returns 6 and caches the result under the list. B) `TypeError`: a list is unhashable and cannot be part of the cache key. C) It returns 6 but never caches it. D) `ValueError`, because maxsize=None is not allowed. |
| Q8 | LO5 | A `@contextlib.contextmanager` function has `yield` and, after it, a cleanup statement, without `try/finally`. The `with` block raises an exception. What happens to the cleanup statement? | A) It runs first, then the exception propagates. B) It runs after the exception has been handled by the caller. C) It does not run: the exception is raised at the `yield` and leaves the generator. D) It runs, and the exception is suppressed. |
