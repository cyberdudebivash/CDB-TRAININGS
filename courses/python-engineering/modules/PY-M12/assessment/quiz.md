Questions are generated from `quiz.yaml`; each is tied to a learning outcome.

|---|---|---|---|
| Q1 | LO1 | A class body contains `items = []` and a method `def add(self, x): self.items.append(x)`. Two instances `a` and `b` are created and `a.add(1)` is called. What is `b.items`? | A) An empty list: each instance has its own `items`. B) `[1]`: the list belongs to the class and both instances see it. C) `AttributeError`: `b` has no attribute `items` until it is assigned. D) `[1]` only on Python versions before 3.12. |
| Q2 | LO1 | Inside `__init__`, a class that keeps a counter in a class attribute `count = 0` does `self.count += 1`. After creating three instances, what is `ClassName.count`? | A) 3. B) 1. C) 0, and each instance now has its own `count` attribute equal to 1. D) It depends on the Python version. |
| Q3 | LO2 | A dataclass `Point` is declared `@dataclass` (not frozen) with fields `x` and `y`. Which statement is true? | A) `Point(1, 2) == Point(1, 2)` is `True`, and `hash(Point(1, 2))` raises `TypeError`. B) `hash(Point(1, 2))` works and equals the hash of every equal point. C) `Point(1, 2) == Point(1, 2)` is `False` because `==` compares identity by default. D) A dataclass cannot define `__eq__`. |
| Q4 | LO2 | An object defines `__eq__` and `__hash__` from a mutable attribute `v`. It is added to a set, then `obj.v` is changed. What does `obj in the_set` return, and why? | A) `True`: a set remembers the object, not its hash. B) It raises `RuntimeError` because the set was modified. C) `True`, because `in` uses `is` first. D) `False` in most cases: the set looks in the bucket of the new hash, and the object is stored under the old one. |
| Q5 | LO3 | A constructor checks `isinstance(cents, int)` to accept whole numbers of cents. Which value passes the check although it should not be accepted? | A) `5.0`. B) `"5"`. C) `True`. D) `None`. |

B) `TypeError`: the signature does not match. C) `True` only if the class inherits from `Speaks`. D) `True`: only the presence of a method named `speak` is checked; a static type checker would report the mismatch. |
| Q8 | LO5 | A notifier calls each subscriber in a loop; one subscriber raises `ValueError`.
